# Viviane Viscardi

Site frontend da massoterapeuta Viviane Viscardi.

- Stack: Vue 3 + Vite + Tailwind CSS
- Domínio: [vivianecviscardi.studiomorh.com](https://vivianecviscardi.studiomorh.com)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
